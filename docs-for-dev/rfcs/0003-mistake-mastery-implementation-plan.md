## 交付范围与顺序

本轮落实可以使用和验收的首期闭环：微信或网页收题经核对进入同一错题库，按标签检索未掌握题，按时间预算推荐复习，持久记录独立作答与提示暴露，审核同类及进阶题，用跨天、迁移与延迟证据关闭错题，并支持抽检失败重开。

现有 SM-2 风格调度作为冷启动；本轮不声称已拟合儿童个体遗忘概率。家庭多孩子授权、自动微信到期提醒、微信内判题和模型参数个体拟合仍属于下一阶段，需要各自验收，不能沿用静态 Demo 的虚拟身份代替真实授权。

| --- | --- | --- | --- |

## 实施约束

1. `resolved` 和本轮 `mastered` 的旧语义保留兼容，但不再代表证据关闭。旧数据不凭空补造独立成功或迁移证据；手动移出与验证掌握分别展示和统计。
2. 客观作答在事务内重新判定。正常提交先持久化答案，再展示反馈；主动查看提示或解析先持久化暴露，未提交退出后重开也不能洗掉记录。无法可靠判分的主观自评不自动形成掌握证据。
3. 首期关闭策略采用至少两次间隔 24 小时的独立原题/抽检成功、另一道同技能变式成功，以及最终验证距此前最近有效成功至少 7 天。阈值有策略版本，属于已确认产品政策，可在试点后调整。
4. 新变式必须是独立题目，关联母错题、目标技能、变化类型与审核状态。生成与审核会展示答案，随后短时练习不能计为未见题独立成功。模型失败应显示真实错误，不使用预设题伪装生成成功。
5. 微信消息与图片来源保留发图者及授权资料空间，确认入库复用原错题与学习记录。相同原图重发不改变已掌握或暂停状态，也不增加复习次数。

## 验收清单

- [x] 微信收题、补拍、重复原图与网页确认的现有测试继续通过。
- [x] 已掌握、暂停和非错题不出现在默认日常推荐，主动检索与抽检有明确入口。
- [x] 10/15/20 分钟题组不超过预算，每题给出可解释推荐原因。
- [x] 同日重复、提示、解析和无法客观确认的自评不提前关闭；看答案但未提交的记录仍生效。
- [x] 满足跨天、同技能变式及延迟条件后生成可追溯关闭决策。
- [x] 正确提前抽检保留既有关闭结论；可信同技能错误重开，新增技能错误不误伤母题。
- [x] 变式生成、审核、练习及失败分支通过服务/API 测试；未审核题不进入正式证据，重复确认不重复建题。真实模型输出质量待联调。
- [x] 不同资料空间中相同数字 ID 的题目、草稿、曝光和复习记录不混合。
- [x] OpenAPI、前端类型、文案和相关测试与最终实现一致。

- 后端相关回归 **240 项通过**，覆盖 practice、掌握规则、推荐、变式、照片入库、题库接口、资料空间隔离及微信收题适配。
- 六组前端交互测试 **54 项通过**；全部 Node 测试 **1,235 项通过**。
- OpenAPI/TypeScript 契约、依赖分层、完整类型检查、本轮文件 ESLint、语言键审计及生产构建通过。中/英/德严格词库覆盖全部已使用键；法/乌按仓库既有回退规则通过。
- 真实浏览器连接临时 SQLite 数据完成：推荐选题与提交、符合条件后自动关闭、关闭历史和证据查看、已掌握筛选、微信样例照片核对入库、年级/知识点/错因保存，以及指定标签的提前复习检索。
- 浏览器预览：`http://127.0.0.1:3017/learning/practice`，后端端口 `8017`，均仅监听本机；使用独立 `DEEPTUTOR_HOME` 验收数据，没有改写实际学习数据库。
- 本轮保留原工作区改动，没有提交 Git 或发布生产。验收中的跨天记录及来图由显式样例数据构造，未伪装成真实学生历史或真实微信消息。

### 上线前及后续阶段

1. 使用真实已绑定微信账号完成发图、回执、补拍、重复投递和网页入库联调；当前验证覆盖适配器与存储路径，没有发送真实微信消息。
2. 配置实际模型后联调识题与变式生成，检查题干、答案、知识范围和审核体验。本轮生成测试注入可控模型响应；正式实现调用现有模型服务，失败如实返回，不回退到预设题。
3. 阿里云部署已完成数据备份、增量迁移、权限及服务验收，见发布记录。家庭多孩子授权、自动微信提醒/微信内作答、个体遗忘参数拟合单独立项。
4. 收集真实延迟表现后评估推荐和关闭策略；本轮通过的是实现规则与操作验收，尚不能当作学习效果试验证据。
